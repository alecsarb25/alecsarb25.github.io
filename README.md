# Alec Agen — Professional Portfolio

Static, responsive professional portfolio for IT leadership, infrastructure operations, and systems architecture.

**Website address (after GitHub Pages is enabled):** https://alecsarb25.github.io/

## Contents
- `index.html`: semantic, accessible single-page portfolio
- `styles.css`: responsive visual design
- `script.js`: small navigation interaction and footer year
- `favicon.svg`: site identity
- `.nojekyll`: disable unnecessary Jekyll processing

## Deployment

In repository **Settings → Pages**, choose **Deploy from a branch**, select **main** and **/(root)**, then **Save**. GitHub will publish the root `index.html` after the Pages deployment succeeds.

## Safety / editing notes

This site is public. It includes project descriptions and public GitHub case-study links only; there are no secrets, server IPs, personal home addresses, internal hostnames, or commercial source code. External Google Fonts stylesheets are loaded for typography. Do not commit private resume content, personal contact details, or configuration files without reviewing them for public disclosure.

The professional experience descriptions are intentionally broad pending review for precision and measurable achievements. No resume PDF or email address is published until verified.
